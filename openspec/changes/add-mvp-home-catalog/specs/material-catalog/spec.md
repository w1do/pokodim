## Purpose

Каталог материалов покодим.рф: помогает посетителю находить статьи, инструкции и обзоры по инструментам и уровню сложности и открывать их для чтения.

## ADDED Requirements

### Requirement: Список материалов
Каталог SHALL отображать список карточек материалов; каждая карточка содержит заголовок, краткое описание, тег инструмента (например Claude Code, Codex, Cursor, Junie), уровень сложности и ссылку на страницу материала.

#### Scenario: Просмотр каталога
- **WHEN** посетитель открывает страницу каталога
- **THEN** отображается список карточек материалов с указанными полями

### Requirement: Фильтрация по инструменту и уровню сложности
Каталог SHALL позволять фильтровать материалы по инструменту и по уровню сложности; выбранные фильтры отображаются в строке запроса (URL) и сохраняются при перезагрузке страницы.

#### Scenario: Фильтр по инструменту
- **WHEN** посетитель выбирает фильтр по инструменту «Claude Code»
- **THEN** в списке отображаются только материалы с этим инструментом, а URL содержит выбранный фильтр

#### Scenario: Сохранение фильтров после перезагрузки
- **WHEN** посетитель обновляет страницу с применёнными фильтрами
- **THEN** фильтры остаются применёнными и список соответствует им

### Requirement: Поиск по материалам
Каталог SHALL предоставлять поиск по материалам по заголовку и описанию; при отсутствии совпадений отображается сообщение об отсутствии результатов.

#### Scenario: Найденные результаты
- **WHEN** посетитель вводит поисковый запрос и запрос даёт совпадения
- **THEN** отображаются карточки материалов, совпавшие по заголовку или описанию

#### Scenario: Пустой результат
- **WHEN** по запросу нет совпадений
- **THEN** отображается сообщение об отсутствии результатов

### Requirement: Страница материала
Каждый материал SHALL иметь страницу по индивидуальному адресу, на которой отображаются заголовок, теги (инструмент, уровень сложности) и содержимое материала.

#### Scenario: Открытие материала по ссылке
- **WHEN** посетитель переходит по ссылке карточки или прямому адресу материала
- **THEN** открывается страница материала с заголовком, тегами и содержимым

#### Scenario: Несуществующий материал
- **WHEN** посетитель переходит по адресу несуществующего материала
- **THEN** отображается страница 404
