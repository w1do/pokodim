## Why

Проект покодим.рф пока не имеет работающего веб-приложения: есть только идея в `IDEA.md`. Чтобы запустить MVP и начать привлекать аудиторию из поиска, нужна главная страница, объясняющая пользу сервиса, и каталог материалов по Vibe Coding — это ядро бесплатного трафика и основа будущей монетизации.

## What Changes

- Создаётся каркас веб-приложения с тёмной темой и акцентным цветом (зелёный/фиолетовый) по визуальному стилю из `IDEA.md`.
- Главная страница с ключевым сообщением «Научись создавать продукты с AI быстрее, дешевле и системнее», карточками материалов и навигацией по разделам.
- Каталог материалов: список карточек с фильтрацией по инструментам (Claude Code, Codex, Cursor, Junie и т.д.) и уровню сложности, поиск по материалам.
- Страница материала с отображением содержимого статьи/инструкции.
- Данные материалов управляются через CMS backend.w1do.ru (категории-инструменты, посты-материалы, теги уровней); сайт читает их через публичный API `/api/v1/content/*`.

## Capabilities

### New Capabilities

- `home-page`: главная страница — hero-блок с ключевым сообщением, навигация по разделам, подборка свежих/избранных материалов.
- `material-catalog`: каталог материалов — список карточек, фильтры по инструменту и уровню сложности, поиск, страница материала.

### Modified Capabilities

(нет — это первый change, существующих specs в `openspec/specs/` нет)

## Impact

- Код: создаётся с нуля (роутинг, страницы, компоненты, модуль чтения публичного API CMS).
- Данные: хранение и управление — CMS backend.w1do.ru (MCP cms-pokodim и admin API); сайт читает материалы через публичный API по public-ключу — модель данных и порядок подключения зафиксированы в design.md.
- Зависимости: стек зафиксирован в design.md (Astro SSG); внешняя зависимость — backend.w1do.ru как источник данных.
- Системы: подключается внешняя CMS — сервис `content` на проекте должен быть включён, public-ключ выпускается оператором в консоли; прочая инфраструктура не создаётся.
