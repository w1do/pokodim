## Purpose

Поведение каталога материалов: постраничная подгрузка курсором, серверные фильтры, состояние фильтров в адресе страницы и корректные состояния загрузки, пустого результата и ошибки.

## ADDED Requirements

### Requirement: Постраничная подгрузка «Показать ещё»
Каталог SHALL загружать материалы порциями по курсору CMS и показывать кнопку «Показать ещё», пока CMS возвращает `next_cursor`. При нажатии каталог SHALL дописывать следующую порцию к уже показанным карточкам. Без `next_cursor` кнопка SHALL быть скрыта.

#### Scenario: Есть следующая страница
- **WHEN** ответ CMS содержит `next_cursor`
- **THEN** под сеткой показана кнопка «Показать ещё»

#### Scenario: Подгрузка
- **WHEN** пользователь нажимает «Показать ещё»
- **THEN** кнопка переходит в состояние загрузки, а новые карточки добавляются после существующих

#### Scenario: Последняя страница
- **WHEN** ответ CMS не содержит `next_cursor`
- **THEN** кнопка «Показать ещё» не отображается

### Requirement: Серверные фильтры
Фильтр по инструменту SHALL передаваться в CMS как параметр `category`, фильтр по уровню — как параметр `tag`. Смена любого фильтра SHALL сбрасывать курсор и загружать первую страницу нового результата. Список инструментов SHALL строиться из категорий CMS, а не из пути материала.

#### Scenario: Фильтр по инструменту
- **WHEN** пользователь выбирает инструмент «Claude Code»
- **THEN** запрос содержит `category` этой категории и каталог показывает только её материалы

#### Scenario: Комбинация фильтров
- **WHEN** выбраны инструмент и уровень
- **THEN** запрос содержит и `category`, и `tag`

#### Scenario: Сброс фильтров
- **WHEN** пользователь нажимает «Сбросить»
- **THEN** фильтры очищаются и показывается первая страница без фильтров

### Requirement: Состояние фильтров в адресе
Выбранные инструмент, уровень и поисковая строка SHALL отражаться в параметрах адреса `?tool=&level=&q=` без перезагрузки страницы. При открытии адреса с параметрами каталог SHALL восстановить фильтры из них.

#### Scenario: Изменение фильтра
- **WHEN** пользователь выбирает уровень
- **THEN** адрес получает параметр `level`, перезагрузки страницы нет

#### Scenario: Открытие готовой ссылки
- **WHEN** пользователь открывает `/materials/?tool=claude-code&level=начинающий`
- **THEN** соответствующие фильтры выбраны, и каталог показывает отфильтрованные материалы

#### Scenario: Неизвестное значение
- **WHEN** в адресе указан несуществующий инструмент
- **THEN** фильтр игнорируется, каталог показывает материалы без этого фильтра

### Requirement: Первая страница из статической сборки
Первая страница каталога без фильтров SHALL попадать в HTML на сборке и использоваться как начальные данные острова, чтобы карточки были видны до загрузки скриптов и не запрашивались повторно сразу после гидрации.

#### Scenario: Открытие без JavaScript
- **WHEN** страница каталога открыта с отключённым JavaScript
- **THEN** первая порция карточек присутствует в HTML

#### Scenario: Гидрация
- **WHEN** остров гидрируется с фильтрами по умолчанию
- **THEN** карточки не мигают и сетевой запрос первой страницы не выполняется сразу

### Requirement: Поиск среди загруженных материалов
Поиск SHALL фильтровать уже загруженные карточки по заголовку и описанию на клиенте без сетевых запросов, потому что серверного поиска в CMS нет. Интерфейс SHALL учитывать, что искомое может находиться в ещё не загруженных порциях.

#### Scenario: Совпадение
- **WHEN** пользователь вводит часть заголовка загруженной карточки
- **THEN** остаются только подходящие карточки

#### Scenario: Нет совпадений, но есть ещё страницы
- **WHEN** среди загруженных карточек совпадений нет, а `next_cursor` есть
- **THEN** показано пустое состояние и доступна кнопка «Показать ещё»

### Requirement: Состояния списка
Каталог SHALL показывать скелетоны карточек при первой загрузке, сохранять прежний список при смене фильтра до прихода нового результата, показывать пустое состояние при отсутствии материалов и состояние ошибки с кнопкой «Повторить» при сбое запроса.

#### Scenario: Смена фильтра
- **WHEN** пользователь меняет фильтр и новый результат ещё грузится
- **THEN** прежние карточки остаются на экране с признаком загрузки, без прыжка вёрстки

#### Scenario: Пустой результат
- **WHEN** сервер вернул ноль материалов для выбранных фильтров
- **THEN** показан текст о том, что ничего не найдено, и кнопка сброса фильтров

#### Scenario: Ошибка сети
- **WHEN** запрос завершился ошибкой
- **THEN** показано сообщение об ошибке и кнопка «Повторить», повторное нажатие заново выполняет запрос

#### Scenario: Быстрая смена фильтров
- **WHEN** пользователь меняет фильтр, пока предыдущий запрос не завершён
- **THEN** предыдущий запрос отменяется, и на экране остаётся результат последнего выбора
