# Деплой в Dokploy

Сайт собирается в статический образ (Astro → `dist/` → nginx). Данные CMS подтягиваются при сборке.

## Настройка

1. В Dokploy создать сервис типа **Docker Compose** и подключить репозиторий.
2. Указать путь к compose-файлу: `infra/docker-compose.yml`.
3. В разделе переменных окружения сервиса задать:
   - `BACKEND_API` — `https://backend.w1do.ru/api`
   - `BACKEND_KEY` — **публичный** ключ проекта (`public`). Ключи `secret` и `agent` сюда не передавать.
4. Назначить домен в Dokploy (маршрутизация через Traefik, порт контейнера `80`).

Значения переменных в репозиторий не коммитятся.

## Выкатка

- Вручную кнопкой **Deploy** в UI Dokploy или через API Dokploy.
- Автодеплой по git-push выключен. Каждая сборка запускается только явно.

## Проверка

После выкатки `GET /healthz` должен вернуть `200 ok`.
